# ☕ Brew & Bean Café

A modern, premium café website concept built with HTML, CSS, and vanilla JavaScript. Designed to deliver an elegant coffee-shop experience with rich photography, smooth animations, and a responsive layout.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Premium café-inspired design and typography
- Smooth scrolling and scroll-triggered animations
- Interactive menu with category filters
- Coffee and pastry photography
- Mobile-friendly navigation
- WhatsApp contact integration
- Email contact link and Google Maps directions
- Accessible controls and reduced-motion support

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Café photography from external image sources

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/brew-bean-cafe.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension, or open the file directly in your browser.
